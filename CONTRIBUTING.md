# Contributing

Use Node 24 and the pnpm version in package.json. Run `pnpm install --frozen-lockfile`, `pnpm test`, and `pnpm build` before proposing changes. CI runs the same checks.

For vocabulary corrections, include the card ID, current text, proposed text and a reliable source where relevant. Do not reorder established IDs. Keep two French examples and Chinese translations per card. Mark mnemonic associations as associations; do not present invented stories as historical etymology. Origins require an authoritative dictionary/source URL.

Do not contribute scraped dictionaries, recordings or images without compatible redistribution rights. Keep source attribution and distinguish code (MIT) from content (CC BY-SA 4.0). Contributions use the applicable existing license. Do not submit secrets or personal progress records.

Use small focused changes. For a new language, first discuss word schema, distractor language, voice locale and data licensing; changing the display label alone is insufficient.
