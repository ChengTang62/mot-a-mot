# Mot à Mot · 法语词卡

面向中文使用者的法语词汇练习 Web App。没有图片，专注于读音、意思、例句和记忆。

**独立开源版：React + TypeScript + Vite，纯静态部署，无需账号、数据库、API 密钥或 ChatGPT。** 学习进度保存在本机浏览器中，不跨设备同步。

## 功能

- 2,100 张词卡：2,000 个生活核心词与表达、100 个专题拓展词，另有基础子集。
- 新词先展示；之后四选一，按下立即反馈对错并自动前进，没有十词一组限制。
- 斩掉已会的词，也能斩掉上一词或撤销。
- 每天复习所有学过且未斩掉的词；独立答对清除当天待复习，设备当地时间零点重置。
- 错题、用过提示的题排到队尾。提示展示两条例句，不带翻译，不计对错，但仍提供答题反馈。
- 每词两条双语例句；1,551 条有效记忆点、49 条附来源的词源说明。暂缺可靠助记的 549 张卡片隐藏记忆点，不用读音或翻译占位。
- 单词自动发音、例句发音、慢速播放与答题音效。使用浏览器语音合成，没有抓取或附带音频文件。

## 本地运行

建议 Node.js 24。安装 `package.json` 中指定版本的 pnpm，然后：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端显示的 localhost 地址。请通过开发服务器运行，不要双击 HTML 文件。

```sh
pnpm test       # 词库、复习逻辑、语音控制、本地持久化检查
pnpm build      # TypeScript 检查及静态构建，输出 dist/
pnpm preview   # 本地预览构建结果
```

## 部署与数据

把 `dist/` 的内容部署到支持 HTTPS 的静态网站托管服务即可。构建使用相对资源路径，可放在域名根目录或项目子目录。

- 使用支持 Web Locks、localStorage、Web Speech 的现代浏览器。写入锁需要 HTTPS 或 localhost。
- 进度保存在 `mot-a-mot-progress-v1` 本地存储键中；偏好另存。重开相同网址、相同浏览器可继续。
- 清理网站数据、隐私浏览结束、浏览器驱逐数据可能导致丢失。换域名、换浏览器或设备不会同步。当前未提供备份导入界面。
- 多标签写入串行处理；另一个标签的界面需刷新才显示最新状态。
- 保存失败会显示错误并保留待重试操作；不会把损坏的记录静默重置成空白。
- 发音由设备/浏览器的法语声音提供。首次自动播放可能需要点击，慢速效果取决于语音引擎。某些语音服务可能联网，因此不是完全离线应用。

该版本保留原版的学习交互，但将原来平台专用的账号与云端数据库替换为本机存储；不包含私人部署地址、账号数据、数据库备份或原项目 Git 历史，也不迁移原网站的云端进度。

## 修改词库

- `lib/words.ts` 汇总词卡；`advanced-words.ts`、`expanded-words.ts`、`daily-words.ts` 扩充内容。
- `lib/examples*.ts` 保存例句；`data/memory-hints.tsv` 保存记忆点。
- `data/word-origins.json` 保存有来源链接的词源故事。
- 全部 2,100 个词都有记忆点。熟悉的英语关联、简单基础词、谐音、拆字和有梗的小故事都可以用，详见[编辑原则](docs/memory-hint-guidelines.md)。
- `F:` 开头的自创内容显示为“趣味联想”，不冒充真实词源；`E:` 是英语关联。真实词源另附来源、单独展示。不再隐藏提示或保留空缺，也不用读音规则、单纯翻译凑数。
- 编辑记忆点或词源后运行 `pnpm generate:memory`，提交生成的 `lib/memory-hints.ts`。
- 已发布的 `fr-XXX` ID 与顺序不能重排，否则会错配用户进度。增加词卡时也要更新校验数量。
- `lib/study.ts` 是复习与队列逻辑；`lib/local-progress.ts` 是可替换的存储接口。

欢迎纠正法语、例句、词源与误导性的助记。详见 [贡献指南](CONTRIBUTING.md)。本版仍以法语为中心，多语言包接口尚未实现。
