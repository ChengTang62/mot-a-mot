# 记忆点编辑原则

每一个词都要有提示。目标是让学习者能从词形、熟悉的声音或已有知识，想起词义；不是要求每个提示都是正式词源。牵强一点、有梗、荒诞的联想也可以，只要能抓住眼前这个词。

- 熟悉的英语词、近形词、中文谐音、字母拆分和具体小故事都可以用。至少给出一个和目标词有关的抓手，再把它接到词义上。
- 自创拆法、谐音和虚构故事在 TSV 中以 `F:` 开头，显示为“趣味联想”。不用装成严肃事实，也不宣称它是实际构词或历史。
- 例如 `poisson` 比 `poison` 多一个 s，可以记成“两个 s 才能放心吃”；`manger` 比 `manager` 少一个 a，可以编成“经理一到饭点只顾着吃”。这些是记忆游戏，不是词源解释。
- `E:` 表示能借力的英语关联；无前缀表示一般记忆点。优先选常用英语，并解释所借用的部分。生僻借词原样重复，通常不如一个简单玩笑有用。
- 从法语基础词联想到目标词时，参照词应明显更简单。不用两个同样难的词循环解释，不靠同族词名单增加负担。
- 不把单纯翻译、释义复述、发音规则、音标或例句复制当成记忆点。中文谐音梗可以用，但它的作用是帮助联想意思，不是教授标准发音。
- 有场景不等于有助记：不能只说“想象你在做这件事”。场景里的关键人物、物件或转折，应来自目标词的字母、谐音或熟悉关联。
- 所有 2,100 个词都必须有非空提示，不允许用 `-`、`null` 或“暂无”藏起难写的词。不好写时，换一种联想方法继续写。
- 真实词源与历史仍保存于 `data/word-origins.json`，附来源链接，并以“词源小故事”单独展示。不能把自创梗写进这一栏。
- 保持简短、可独立理解。尽量一两个弯就能回到词义，不要求学习者先认识另一个更难的词。

编辑 `data/memory-hints.tsv` 后运行 `node scripts/generate-memory-hints.mjs`，再运行 `node scripts/check-vocabulary.mjs`。检查要求全部词卡有提示、ID 与例句不变，并拒绝常见的读音填充；程序只能检查完整性，不能保证每个笑话对每个人都有效，欢迎逐条改进。
