# 记忆点编辑原则

记忆点要帮助学习者从已知信息记住眼前的词，不能把学习负担转移到另一个同样难、或更难的法语词上。

- 优先用常见英语中形义相近的词。把“相似线索”和真实同源关系区分开；没有来源，不宣称同源。
- 法语构词解释只从更基础、更常用的词走向目标词。例如 `demain → après-demain` 可以；用 `après-demain` 解释 `demain` 不可以。不能只因词形更短就认定更容易。
- 不用名词、动词、形容词互相循环解释，也不罗列同族词。例如不再用 `savonner` 解释 `savon`，或用 `commissaire` 解释 `commissariat`。
- 不编造场景、表情或物体形状来重复词义，不用无关近形词硬凑联想，不退回搭配记忆。
- 有可靠资料时可介绍词源、历史、品牌或地名来历。用中文解释线索，不要求先掌握古语词；简短改写并把来源链接放入 `data/word-origins.json`。
- 找不到可靠关联时，可以给具体的读音、拼写、语法或词义边界要点。不声称每个词都有英语同源词，也不编造词源。
- 保持提示短、可独立理解。例句已经由独立区域展示，提示不应只复制例句或中文释义。

编辑 `data/memory-hints.tsv` 后运行 `node scripts/generate-memory-hints.mjs`。生成器检查常见禁用写法，无法自动判断一个关联是否更容易，因此仍需逐条校对；再运行 `node scripts/check-vocabulary.mjs` 检查完整性。

本次校订覆盖全部 2,100 条提示，替换了反向派生、陌生词互释和空泛场景等内容，保留有用的基础构词与语法关系。词卡 ID、词义、例句和学习记录结构均未改动。
